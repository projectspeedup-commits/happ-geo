# happ-geo

Lightweight `geoip.dat` and `geosite.dat` for split routing in Xray-based clients.

Built daily from [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat):
only the categories below are kept, entries are copied unchanged.

- geoip: `ru`, `private`
- geosite: `category-ru`, `google`, `youtube`, `openai`, `anthropic`, `category-ai-!cn`,
  `deepseek`, `private`, `yandex`, `mailru`, `vk`

Download:

- https://github.com/projectspeedup-commits/happ-geo/releases/download/geo/geoip.dat
- https://github.com/projectspeedup-commits/happ-geo/releases/download/geo/geosite.dat
